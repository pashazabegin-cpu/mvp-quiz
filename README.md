# MVP Квизмас — лендинг (прототип)

Одностраничный сайт события «MVP Квизмас» (13 декабря 2026, Avulus Cyber Space).
Сейчас это **прототип**: серая палитра, заглушки вместо картинок, «рыба» вместо части текстов.
Структура экранов и все анимации уже рабочие: дизайн накладывается поверх через токены и картинки.

## Стек

| Что | Зачем |
| --- | --- |
| [Astro 7](https://docs.astro.build) + TypeScript | компоненты по экранам, на выходе обычные статичные HTML/CSS/JS |
| [GSAP 3](https://gsap.com/docs/v3/) — ScrollTrigger, SplitText | анимации при скролле, разбивка текста на строки и буквы |
| [Lenis](https://github.com/darkroomengineering/lenis) | плавный инерционный скролл |
| WebGL (свой шейдер, без библиотек) | живой фон в квизе и в блоке билета |
| Canvas 2D | снег |

Все пакеты бесплатные, включая плагины GSAP.

## Запуск

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # статичная сборка в dist/
npm run preview  # посмотреть сборку
npm run check    # проверка типов
```

Нужен Node.js 20+ (проверено на Node 24).

## Структура

```
src/
  data/content.ts          ← ВСЕ тексты, ссылки, пути к картинкам
  styles/tokens.css        ← цвета, шрифты, размеры, тайминги (дизайн-токены)
  styles/global.css        ← reset, кнопки, чипы, карточки, заглушки, начальные состояния анимаций
  layouts/Base.astro       ← <head>, шрифты, меню, подключение скриптов
  pages/index.astro        ← порядок экранов
  components/
    sections/              ← по файлу на экран: Hero, About, Schedule, Talks, Quiz,
                             Speakers, Jury, Tickets, Partners, Location, Faq, Footer
    ui/                    ← Button, Placeholder, Nav, Socials, NyMark, Anno, AnnotationsToggle
  scripts/
    main.ts                ← точка входа: что и когда включается
    core/                  ← окружение (reduced motion, тип указателя), плавный скролл
    animations/            ← интро, появления, параллакс, таймлайн, «табло»
    interactions/          ← наклон, пятно света, магнит, разбегание, параллакс от курсора
    ui/                    ← меню, лента спикеров, аккордеон, переключатель разметки
    effects/               ← WebGL-фон, снег
public/media/hero.mp4      ← видео первого экрана
```

Стили каждого экрана лежат внутри его `.astro`-файла (они изолированы и не влияют на другие блоки).

## Как править

- **Тексты, ссылки, фото, логотипы** — только `src/data/content.ts`. Картинки класть в `public/media/…`
  и прописывать путь в поле `photo` / `logo`. Пока поле пустое, на месте картинки рисуется заглушка.
- **Цвета, шрифты, отступы** — `src/styles/tokens.css`. WebGL-фон берёт цвета оттуда же
  (`--c-bg`, `--c-accent`, `--c-accent-2`), так что перекрашивается вместе со страницей.
- **Порядок экранов** — `src/pages/index.astro`.
- **Новогодние элементы** — компонент `NyMark`: `<NyMark style="top: 10%; left: 5%; width: 90px" src="/media/ny/star.png" />`.
  Без `src` это пунктирная заглушка, видимая только в режиме разметки.

## Адаптив

Две раскладки по макетам Figma, переключаются по форме экрана (`MOBILE_QUERY` в `scripts/core/stage.ts`
и тот же `@media (max-aspect-ratio: 1/1)` в стилях экранов):

- **шире, чем выше** (ноутбуки, мониторы, планшеты горизонтально) — кадр 1440×900, масштаб `min(ширина/1440, высота/900)`,
  по ширине тянется сетка колонок;
- **не шире своей высоты** (телефоны, планшеты вертикально, узкие окна) — мобильный кадр 375
  (секция «Квизмас · Mobile 375»), масштаб `min(ширина/375, высота/640, 1.5)`: экран целиком влезает
  даже на 320×568, а на планшете колонка шире, шрифт не раздувается. Нижнего меню здесь нет;
- **телефон горизонтально** (сенсорный экран ниже 500 px) — просьба повернуть (`ui/RotateHint.astro`).

Ручные переносы строк: `br-d` — только в десктопной раскладке, `br-m` — только в мобильной.

## Анимации: какие атрибуты что делают

Анимации подключаются data-атрибутами в разметке, чтобы их можно было переиспользовать и легко найти поиском.

| Атрибут | Эффект | Файл |
| --- | --- | --- |
| `data-hero-*` | интро первого экрана, видео уезжает при скролле | `animations/hero.ts` |
| `data-split` | заголовок выезжает построчно из-под маски | `animations/reveal.ts` |
| `data-reveal` | блок всплывает при появлении | `animations/reveal.ts` |
| `data-stagger` | дети всплывают лесенкой | `animations/reveal.ts` |
| `data-parallax="0.3"` | параллакс от скролла (число — скорость, минус — навстречу) | `animations/parallax.ts` |
| `data-timeline` / `data-tl-item` | линия расписания заполняется, точки загораются | `animations/timeline.ts` |
| `data-sticky-list` / `data-sticky-item` | закреплённый заголовок: счётчик, прогресс, фокус на текущей карточке | `animations/sticky-list.ts` |
| `data-schedule-list`, `data-talks-list` | экран закреплён, пункты едут вверх «гармошкой» (каждый отстаёт от предыдущего) | `animations/lag-list.ts` |
| `data-spin` | кадр видео с логотипом задаёт скролл (видео перекодировано: каждый кадр ключевой) | `sections/logo-spin.ts` |
| `data-nav-light` | над этим участком меню переключается на тёмный текст | `ui/nav.ts` |
| `data-scramble` | цифры/буквы перебираются как на табло | `animations/scramble.ts` |
| `data-tilt="8"` | 3D-наклон за курсором (число — макс. угол) | `interactions/tilt.ts` |
| `data-spotlight` | пятно света под курсором (+ CSS-переменные `--mx`, `--my`, `--gx`) | `interactions/spotlight.ts` |
| `data-pointer` | только переменные `--mx`/`--my`, визуал в CSS компонента | `interactions/spotlight.ts` |
| `data-magnetic="0.3"` | кнопка тянется за курсором | `interactions/magnetic.ts` |
| `data-repel="160"` | дети разбегаются от курсора (число — радиус) | `interactions/repel.ts` |
| `data-depth="1.5"` | слой двигается за курсором (глубина) | `interactions/mouse-depth.ts` |
| `data-rail` | горизонтальная лента: свайп, drag мышью с инерцией, стрелки, прогресс | `ui/rail.ts` |
| `data-accordion` | плавное раскрытие `<details>` | `ui/accordion.ts` |
| `canvas[data-shader]` | живой WebGL-фон, тянется к курсору | `effects/shader-background.ts` |
| `canvas[data-snow]` | снег, разлетается от курсора | `effects/snow.ts` |

Начальные (скрытые) состояния элементов заданы в `global.css` под классом `.js-motion`,
поэтому до запуска JS ничего не «мигает». Если скрипты не загрузились за 3,5 с, контент показывается без анимаций.

## Доступность и производительность

- Системная настройка «уменьшить движение» (`prefers-reduced-motion`) отключает плавный скролл,
  появления, параллакс, снег и анимацию фона. Меню, аккордеон и лента работают как обычно.
- Эффекты под курсор (наклон, магнит, свет, разбегание) включаются только на устройствах с мышью/тачпадом.
- WebGL-фон рендерится в половинном разрешении и, как и снег, ставится на паузу вне экрана.
- Без WebGL канвас удаляется, остаётся CSS-фон секции.

## Слой разметки прототипа

Кнопка «Разметка» внизу справа показывает номера экранов (как в ТЗ), заметки из ТЗ,
подписи анимаций (⚡), заглушки текста (жёлтая рамка) и места под новогодние элементы.
Наведите на кнопку — появится легенда. **Перед публикацией** поставьте `site.annotations = false`
в `src/data/content.ts` — слой не попадёт в сборку.

## Публикация

`npm run build` → папка `dist/` — обычная статика, её можно залить на любой хостинг или отдать в CMS.
Если страница будет жить в подпапке (например `mvpa.ru/quizmas/`), укажите `base: '/quizmas'`
в `astro.config.mjs` — пути к файлам пересчитаются автоматически.
